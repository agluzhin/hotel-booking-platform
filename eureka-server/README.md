# Eureka Server

Реестр обнаружения микросервисов Spring Cloud Netflix Eureka. Порт `8761`. Модуль не предоставляет бизнес-эндпойнтов: сервисы регистрируются в реестре, Gateway и Booking Service находят их по имени.

## Конфигурация

- `spring.application.name=eureka-server` — имя реестра.
- Регистрация и получение реестра самим Eureka отключены.
- URL реестра для клиентов: `http://localhost:8761/eureka/`.

## Запуск

Общие требования к JDK/Maven описаны в [корневом README](../README.md).

```bash
mvn -pl eureka-server spring-boot:run
```

Проверить реестр можно в браузере: [http://localhost:8761](http://localhost:8761). После запуска остальных сервисов список приложений должен содержать `API-GATEWAY`, `BOOKING-SERVICE` и `HOTEL-SERVICE`.

## Как проверить модуль

1. Запустить Eureka и открыть dashboard.
2. Убедиться, что при запуске модулей-клиентов они появляются в списке.
3. Остановить Eureka и проверить журнал клиентов: при недоступности реестра сервисы не смогут выполнить регистрацию/discovery.

Eureka не имеет JUnit-тестов бизнес-логики: назначение модуля — интеграционная регистрация и обнаружение. Проверку всей системы выполняйте командой `mvn clean verify` из корня.
